SQL Injection

Week 8 · Database Security

What is it?

SQL Injection happens when an attacker inserts malicious SQL code into an input field. The database then executes that code as if it were a legitimate query, giving the attacker access to data they shouldn't have.

How does it work?

Imagine a login form that runs this query behind the scenes:

SELECT * FROM users WHERE username='input' AND password='input'

If an attacker types ' OR '1'='1 as the username, the query becomes:

SELECT * FROM users WHERE username='' OR '1'='1' AND password=''

Since '1'='1' is always true, the attacker bypasses the login completely.

What I practiced

In the TryHackMe room I practiced extracting database tables, usernames and passwords using injected queries. I also used UNION attacks to retrieve data from other tables in the database.

How to prevent it

Always use parameterised queries which treat user input as data, never as code. Also validate and sanitise all input and use least privilege database accounts.
